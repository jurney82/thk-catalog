# THK 카탈로그 검색 (태광베어링 사내용)

THK·삼익THK 카탈로그에서 형번 스펙 검색, 계산기 7종, 형번 비교표, 형번 풀이(HSR·SHS·SSR·SRS)를 제공하는 정적 웹페이지입니다.

- 접속: https://jurney82.github.io/thk-catalog/ (접근 비밀번호 필요)
- 값은 카탈로그 PDF에서 자동 추출한 참고값입니다. 고객 제출 전 원본 페이지(원본 PDF)로 확인하세요.
- 구성: `index.html`(화면) · `data.js`(본문 색인) · `specs.js`(형번 스펙) · `pg/`(페이지 그림) · `원본쪽/`(쪽별 원본 PDF) · `catalog/`(카탈로그 전체 PDF)
